# MkDocs Custom Theme

## Описание

Проект представляет собой кастомизированный статический сайт на базе MkDocs с собственной темой.

## Особенности темы

- Кастомный header с навигацией
- Стилизованный контент
- Фиксированный footer
- Адаптивный дизайн
- Оптимизированные стили и скрипты

## Процесс сборки

1. Валидация HTML с помощью html5validator
2. Обработка CSS через PostCSS (autoprefixer + cssnano)
3. Сборка сайта с помощью MkDocs
4. Деплой на GitHub Pages

## Локальная разработка

1. Установите зависимости:
```bash
pip install mkdocs
npm install -g postcss postcss-cli autoprefixer cssnano
```

2. Запустите сервер разработки:
```bash
mkdocs serve
```
